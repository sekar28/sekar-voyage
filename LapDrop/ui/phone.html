      Add LapDrop to the Share menu

      One-time setup on iPhone or iPad. Afterwards: Share → LapDrop from Photos, Files or any app.

      Show the steps
      1. Copy this address:

        Use this one, not the page's own link: it starts with http:// and uses port 8765, which the Shortcuts app accepts.

      2. Open the Shortcuts app, tap + and name the shortcut LapDrop.
      3. Tap the i (or the shortcut's name) and switch on Show in Share Sheet. Set it to receive Images, Files and Media (or Any).
      4. Add the action Repeat with Each, with Shortcut Input as its input.
      5. Inside the repeat, add Get Contents of URL and paste the address.
      6. Tap the arrow on that action: Method = POST, Request Body = Form.
      7. Add new field → File. Key: file. Value: Repeat Item. No other fields are needed.
      8. Tap Done. In Photos, tap Share → LapDrop. The first time, allow Shortcuts to use the local network.

      If it says it can't connect, the laptop's name may not work on this network. Use the IP address instead (it changes when the network does):

      LapDrop must be open on the laptop. If someone taps "New code" there, these addresses change: paste the new one into the shortcut.

      Link not valid

      Scan the QR code on the laptop again to reconnect.
