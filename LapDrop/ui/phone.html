      Add LapDrop to the Share menu

      One-time setup on iPhone or iPad. Afterwards: Share → LapDrop from Photos, Files or any app.

      Show the steps
      1. Copy this address:
      2. Open the Shortcuts app and tap +. Rename the shortcut to LapDrop.
      3. Tap the i button and switch on Show in Share Sheet.
      4. Add the action Repeat with Each, and set its input to Shortcut Input.
      5. Inside the repeat, add Get Contents of URL and paste the address.
      6. Open that action's options: set Method to POST and Request Body to Form.
      7. Tap Add new field, choose File, type file as the key and pick Repeat Item as the value.
      8. Tap Done. The first time you use it, allow Shortcuts to reach the local network.

      LapDrop must be open on the laptop. Tap "New code" there and this address changes too.
